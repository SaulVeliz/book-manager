# Book Manager

## Sprint

Sprint 1

## Objetivo

Sistema de gestión de libros para librería.

## Funcionalidades

- CRUD de Libros
- CRUD de Géneros
- CRUD de Editoriales
- CRUD de Monedas
- CRUD de Precios
- CRUD de Stock
- CRUD de Tipos de Cotización
- CRUD de Cotizaciones

## Persistencia

Persistencia mediante archivos CSV.

## Ejecución

python3 -m book_manager.main
