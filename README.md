## Objetivo
Desarrollar una aplicación de consola para la gestión de una librería utilizando Programación Orientada a Objetos, persistencia en base de datos relacional y consultas a servicios externos.

## Introducción
Book Manager es una aplicación de consola desarrollada en Python que permite administrar el inventario de una librería mediante operaciones CRUD completas.
El sistema gestiona libros, géneros, editoriales, monedas, precios, stock, tipos de cotización y cotizaciones del dólar.
Durante el Sprint 1 se implementó la persistencia utilizando archivos CSV.
Durante el Sprint 2 se realizó la migración completa a una base de datos relacional utilizando SQLAlchemy.

## Contexto del Sprint 2
El objetivo principal del Sprint 2 fue reemplazar la persistencia basada en archivos CSV por una base de datos SQLite utilizando SQLAlchemy como ORM.

Además, se realizó la migración completa de datos desde CSV, se implementó el consumo de una API externa para obtener cotizaciones del dólar y se incorporaron reportes bimonetarios y exportación de datos.
